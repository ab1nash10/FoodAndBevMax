# AAHAR - UI Reference

Version: 1.0

## Purpose

This document defines the visual direction for AAHAR.

All future UI development must follow:

* docs/UI_UX_GUIDELINES.md
* docs/UI_REFERENCE.md

---

# Product Vision

AAHAR should feel like:

* Modern SaaS Product
* Enterprise Inventory Platform
* Restaurant Operations Platform
* Hospital Operations System
* Finance / ERP Dashboard

Avoid:

* Old ERP UI
* Excel-style screens
* Bootstrap admin templates
* Crowded hospital software

---

# Design Style

Use:

* Clean layouts
* Large KPI cards
* Rounded cards
* Modern tables
* Soft shadows
* Light theme (default)
* Dark theme (optional)
* Responsive design

Target quality:

* Linear
* Stripe Dashboard
* Modern Inventory Platforms
* Modern Restaurant Management Platforms

---
